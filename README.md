# ImmoSim
 
## Description

ImmoSim is a suite of real estate simulators tailored for the French market. These tools are designed to assist users in evaluating property investments, estimating value evolution, and comparing different scenarios.

## Tech Stack

- HTML
- CSS
- JavaScript

## Key Features

- **Value Simulator:** Estimate the future value of a property based on various factors.
- **Investment Simulator:** Analyze the profitability of rental investments.
- **Comparison Tool:** Compare different investment scenarios side-by-side.
- **Purchasing Power Calculator:** Determine your real estate buying power.

## Data Storage

All data is stored exclusively on the client-side, ensuring user privacy and data security.
